# Ball catalogue

Local native catalogue: 21 base balls, 69 named evolutions, 90 recipe routes. Ingredient order does not matter. Every ingredient must be level 3; the evolution starts at level 1. See [correction scope and balance limits](MECHANICS_CORRECTIONS.md).

## Base balls

| Ball | Effect |
| --- | --- |
| Bleed | Applies two bleed stacks. Each later ball hit triggers bleed damage; maximum eight stacks. |
| Brood Mother | Each enemy hit has a 25% chance to spawn a baby ball. |
| Burn | Adds a three-second burn stack, up to three stacks. Each stack deals fire damage over time. |
| Cell | Splits into a clone on hit, twice per lineage. |
| Charm | Each hit has a 4% chance to charm for five seconds. Charmed enemies move upward and attack enemies. |
| Dark | Deals triple impact damage and is destroyed on impact. Three-second cooldown. |
| Earthquake | On impact, damages a three-by-three-tile area. |
| Egg Sac | Breaks on an enemy into two to four baby balls. Three-second cooldown. |
| Flesh | Starts at half impact damage. Each bounce increases speed by 25%. |
| Freeze | Has a 4% chance to freeze for five seconds. Frozen targets take 25% more damage. |
| Ghost | Passes through enemies without bouncing off them. |
| Iron | Deals double impact damage but travels 40% slower. |
| Laser (Horizontal) | On hit, damages all enemies in the same row. |
| Laser (Vertical) | On hit, damages all enemies in the same column. |
| Light | Blinds enemies for three seconds, reducing detection and giving their attacks a 50% miss chance. |
| Lightning | On hit, lightning strikes up to three nearby enemies. |
| Poison | Applies poison for six seconds, stacking up to five times. |
| Stone | Starts at 300% impact damage. Each enemy hit erodes damage by 40%, to a 50% minimum. |
| Time | Impact leaves a freezing snare for 2 / 2.5 / 3 seconds. |
| Vampire | Each hit has a 4.5% chance to heal one health. |
| Wind | Passes through enemies and slows them by 30% for five seconds. Impact damage is reduced by 25%. |
